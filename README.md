# Сроки

Android-приложение для учёта сроков годности товаров: сканирование кодов
«Честного ЗНАКа» и обычных штрихкодов, справочник 1С, напоминания,
резервные копии и автообновление.

Репозиторий используется только как хранилище релизов: приложение
«Сроки» раз в сутки проверяет последний релиз и предлагает установить
новую сборку.

## Как установить

1. Откройте раздел **Releases**.
2. Скачайте файл `Sroki-v<версия>-b<сборка>-release.apk`.
3. Откройте его на телефоне и разрешите установку из этого источника.

## Что лежит в релизе

| Файл | Назначение |
|---|---|
| `Sroki-v<версия>-b<сборка>-release.apk` | Само приложение |
| `version.json` | Номер версии и сборки для проверки обновлений |

Номер сборки увеличивается на каждом выпуске. Если номер сборки в
`version.json` больше установленного, приложение предложит обновление.

## Автообновление

В приложении: **Настройки → Обновления → `mah96/sroki`**. Android при
установке всегда спрашивает подтверждение — тихо обновлять APK система
не позволяет.
